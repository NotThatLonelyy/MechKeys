# Optional sound packs

Ready-to-import Mechvibes V2 packs. They are **not** inside the mod jars. Import them in-game: press **K** > **Profiles / Import** > **Import...** and give MechKeys the path to a `.zip` from this folder (or use **Browse...**). Step by step: [../docs/SOUNDPACKS.md](../docs/SOUNDPACKS.md).

* `Keyboard/` - 7 packs
* `Mouse/` - 4 packs

Licenses: the keyboard packs say "Personal use only" (see [../NOTICE.md](../NOTICE.md)).
